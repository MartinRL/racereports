# Race Reports

Ultracycling race reports, published with [Quartz v4](https://quartz.jzhao.xyz) at https://racereports.rosenlidholm.se.

- `content/<slug>.md`: English report (default language)
- `content/sv/<slug>.md`: Swedish report
- `content/bilder/<slug>/`: images, shared between languages

Reports are published from the Obsidian RR project with the `/publish-rr` skill. Push to `main` deploys via GitHub Pages.
